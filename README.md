# 🌐 Personal Portfolio - Nikita Soam

This is my personal developer portfolio, showcasing my skills, projects, and contact information. The site is fully responsive and built using HTML, CSS, and JavaScript.

🔗 **Live Site:** [https://nikitasoam7.github.io/Portfolio/](https://nikitasoam7.github.io/Portfolio/)

---

## ✨ Features

- **Navigation Menu**  
  A right-aligned menu with internal links:  
  `Home | Projects | Contact` — clicking on each scrolls smoothly to the respective section.

- **About Me Section**  
  Includes a short bio about me on the left and my photo on the right.

- **Projects Section**  
  Displays a list of my featured projects, each linked directly to its GitHub repository for more details.

- **Contact Section**  
  Shows my contact information at the bottom of the page for easy communication.
